# Standard Laptop Task Flow Automation

Welcome to the **Standard Laptop Task Flow Automation** project repository! This project automates the creation of a Catalog Task for Standard Laptop requests using ServiceNow's Flow Designer.

---

## 📌 Project Overview
The primary objective of this project is to eliminate manual task creation, improve processing speed, and ensure approved laptop requests are automatically routed to the appropriate IT team. 

- **Platform Used:** [ServiceNow Developer Platform](https://developer.servicenow.com/dev.do#!/home)
- **Target Audience / Department:** IT Procurement & Hardware Configuration Team
